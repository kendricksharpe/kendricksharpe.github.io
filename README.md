# kendricksharpe.com

A static reading list hosted on GitHub Pages. The homepage contains the reading list only, with its book links and favorites preserved. The old `/reading-list/` address redirects to `/`.

## Editing and publishing

Edit `index.html` or `assets/site.css` directly. No build system is required. Push changes to `main` to publish through GitHub Pages at https://kendricksharpe.com/.

GitHub Pages is configured to deploy from the `main` branch and repository root. `CNAME` retains the custom domain. The site serves HTML, CSS, and a locally hosted font, with no WordPress or PHP dependency.
